- Added local icon history. Generated variants and prompts are saved on this Mac, so you can revisit a design, continue editing, or export it again.
- Added history actions to copy a prompt, reveal the last export in Finder, or remove an icon from history without deleting exported files.
- Added a retry action and a warning before quitting if a generation cannot be saved to history.
- Improved detection of ChatGPT and Codex apps, including renamed apps and installations outside the usual Applications folders.
- Added **Browse…** and **Change…** to choose an app location with the native macOS file picker. The connection is checked before the location is saved.
- Improved connection recovery: retry detection from the missing-app screen, or let automatic detection try another installation when one cannot start.
