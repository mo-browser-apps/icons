Generate Mac app icons with your ChatGPT account, choose image models for your API connection, and export icons with the same shape and shadow you see in the preview.

## Generate with your ChatGPT account

Choose **ChatGPT** in the connection screen to use your existing account through the desktop app. No API key is needed for this connection. The setup wizard helps you find a compatible installation, sign in, or update it.

Generation uses your plan’s allowance and available credits. Account limits apply; connecting alone does not start generation. The integration uses Codex, and compatible Codex CLI installations are also supported.

![MōIcons offers a ChatGPT connection or an OpenAI or OpenRouter API key](https://raw.githubusercontent.com/mo-browser-apps/icons/v1.1.0/docs/releases/assets/moicons-chatgpt-blue.png)

## Choose models for your API connection

Open generation settings to choose an available image model and its supported quality options for OpenAI or OpenRouter. MōIcons remembers your choices separately for each provider. ChatGPT manages model and quality for its connection.

## Export the icon you preview

The preview and exported files now share the same macOS icon contour, transparent margins, smooth edges, and soft shadow. Save an `.icns` file and a companion `.iconset` folder with all ten standard image sizes. Refinement uses the original artwork, so export margins and shadows do not accumulate with each edit.

## More reliable generation and attachments

- Stopping or failing regeneration preserves the previous variants and selection.
- Stop interrupts active requests and retries. Requests already processed by the provider may still count toward usage.
- Attach, paste, or drop one reference image. Invalid images show an error and leave the previous reference intact.
- A successful response that cannot be read no longer triggers another paid generation attempt.
- API keys are checked before opening model settings and can be removed from the app.

MōIcons also moves to MōBrowser 2.19.0 and includes a refreshed app icon.
